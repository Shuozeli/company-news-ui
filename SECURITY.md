# Security policy

## Reporting a vulnerability

Please report sensitive vulnerabilities through the repository's
[private vulnerability reporting form](https://github.com/Shuozeli/company-news-ui/security/advisories/new).
Do not open a public issue containing exploit details, credentials, private
data, or an unpatched vulnerability.

Include the affected URL or commit, impact, reproduction steps, and any
suggested mitigation. Reports are reviewed on a best-effort basis; a maintainer
will coordinate disclosure after a fix is available.

Non-sensitive availability problems, broken public links, and rendering bugs
can use the normal issue templates.

## Scope

This repository contains a static client. Vulnerabilities in crawling,
normalization, or data publication should be reported to
[`company-feed-server`](https://github.com/Shuozeli/company-feed-server/security)
or [`company-news-data`](https://github.com/Shuozeli/company-news-data/security)
as appropriate.
